## v0.5 — why a public-data-only first paper

The two-stage strategy ships v0.5 quickly (~6 months) without waiting on the multi-month IRB + prospective-acquisition critical path. v0.5's contribution is the **harmonization layer + multi-anchor content-addressed manifest + credential format**, not the underlying scans (which already exist in the cited sources). v1.0 then adds the multi-vendor real-paired-dose contribution as a separate, complementary paper.

## v0.5 — submission notes

*Nature Scientific Data* requires the dataset to be deposited on a stable public repository (PhysioNet here) before submission. For v0.5 the deposit is the **code + manifests + top-up annotations**, not redistributed DICOM; users obtain the underlying scans from each source's gatekeeper and run our preprocessing pipelines locally.

The Data Descriptor format is shorter than a typical research paper: ~3500-5000 words total, with the heaviest weight on Methods + Technical Validation. v0.5 is at the upper end of this range because the harmonization-protocol Methods section is substantive; reviewers tolerate length when the protocol detail is the contribution.

NSD reviewer concerns specific to v0.5:
- **Novelty pushback**: "Is harmonization-of-existing-datasets enough?" Address by emphasizing the five orthogonal contributions (unified Docker preprocessing pipelines / unified Python loader / multi-anchor content-addressed manifest / harmonized + topped-up annotations / framework-credentialed baselines) and pointing to v1.0 as the planned follow-up with new data.
- **Vendor coverage** (corrected 2026-05-26): the public Mayo LDCT-PD cohort is actually **two-vendor — ~99 GE + ~101 Siemens** (verified from TCIA metadata + a GE projection file), so the earlier "Siemens-only" claim was a factual error. The manuscript now reports the GE/Siemens split accurately and **promotes cross-vendor (GE↔Siemens) paired-dose coverage as a v0.5 strength**; v1.0's distinction is re-scoped to prospective + multi-site + additional vendors (Canon/Philips) + new tasks.
- **Dose-nature wording** (corrected 2026-05-26): AAPM/Mayo "low-dose" is Mayo's validated projection-domain **noise insertion** from the real full-dose projections, not a second physical scan. The manuscript now says so throughout (abstract/Background/acquisition table/Technical Validation/limitations); the sim-vs-"real" validation is reframed as **simulation vs. the noise-insertion reference**. Code keeps the `low_dose_real` identifier as shorthand for *measured-reference vs. our-simulation* (defined in `schema/dataset_schema.md` §3); truly re-acquired paired dose is a v1.0 distinction.
- **Single-source-annotation pushback**: "Most of your annotations are inherited from LIDC, not new." Address as a feature (harmonizing existing community annotations is the contribution; we top up the gaps rather than re-collect, saving ~$80K in annotation honoraria that would otherwise be wasted).
- **Journal-fit / "data vs. software" pushback** (addressed in the 2026-05-25 reframe): Data Records now *leads with the new deposited data records* (annotations, LIDC-derived simulated low-dose, harmonized metadata, splits, manifest), grouped by license/availability, so the descriptor is anchored on data rather than code; the loader/pipelines are positioned as the access mechanism. This is the single most important framing change for a *Scientific Data* desk-screen.
- **Blockchain-credibility / competing-interests pushback** (addressed in the 2026-05-25 reframe): PhysioNet DOI + Zenodo + the SHA-256 content hash are now the primary, journal-recognized deposit/citation channels; the IPFS replica and the PWM L3 registry entry are demoted to a single optional "mirror" sentence throughout (abstract, Data versioning, Code Availability); and the PWM Protocol Foundation affiliation is now declared in a real Competing Interests statement.
