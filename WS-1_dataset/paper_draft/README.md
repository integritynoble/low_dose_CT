## v0.5 — why a public-data-only first paper

The two-stage strategy ships v0.5 quickly (~6 months) without waiting on the multi-month IRB + prospective-acquisition critical path. v0.5's contribution is the **harmonization layer + multi-anchor content-addressed manifest + credential format**, not the underlying scans (which already exist in the cited sources). v1.0 then adds the multi-vendor real-paired-dose contribution as a separate, complementary paper.

## v0.5 — submission notes

*Nature Scientific Data* requires the dataset to be deposited on a stable public repository (PhysioNet here) before submission. For v0.5 the deposit is the **code + manifests + inherited LIDC annotations**, not redistributed DICOM; users obtain the underlying scans from the LIDC gatekeeper and run our preprocessing pipelines locally. (AAPM/Mayo DICOM are not part of v0.5; they are v1.0 roadmap additions.)

The Data Descriptor format is shorter than a typical research paper: ~3500-5000 words total, with the heaviest weight on Methods + Technical Validation. v0.5 is at the upper end of this range because the harmonization-protocol Methods section is substantive; reviewers tolerate length when the protocol detail is the contribution.

NSD reviewer concerns specific to v0.5:
- **Novelty pushback**: "Is harmonization-of-existing-datasets enough?" Address by emphasizing the five orthogonal contributions (unified Docker preprocessing pipeline / unified Python loader / multi-anchor content-addressed manifest / harmonized LIDC annotations + simulated low-dose / framework-credentialed baselines) and pointing to v1.0 as the planned follow-up with new data + the two additional public sources.
- **Vendor coverage (v0.5, updated 2026-08-18)**: v0.5 is LIDC-only; the LIDC cohort is **four-vendor (GE / Siemens / Philips / Toshiba; ≈669 / 201 / 74 / 66)** full-dose real reconstructions, with reduced-dose **simulated** (projection-domain thinning at dose ratios 0.10/0.25/0.50). The Mayo LDCT-PD cohort (≈99 GE + ≈100 Siemens, 199 total) with its validated noise-insertion reference low-dose is a **v1.0 roadmap** addition; the earlier "GE↔Siemens paired-dose as a v0.5 strength" framing is therefore re-scoped: v0.5's vendor breadth is LIDC's four-manufacturer image coverage, v1.0 adds the two-vendor (GE/Siemens) real-paired-dose coverage plus prospective multi-site vendors (Canon/Philips). *(Note: the GE/Siemens counts for Mayo must sum to the 199-patient public cohort; the exact per-vendor split is pending extraction from the deposited `metadata.json` at v1.0 build time — see the acquisition-table provenance flag.)*
- **Dose-nature wording** (corrected 2026-05-26): AAPM/Mayo "low-dose" (v1.0 roadmap) is Mayo's validated projection-domain **noise insertion** from the real full-dose projections, not a second physical scan; v0.5 reduced-dose is our **simulation** (projection-domain thinning) and the sim-vs-"real" validation is therefore a v1.0 roadmap item. Code keeps the `low_dose_real` identifier as shorthand for *measured-reference vs. our-simulation* (defined in `schema/dataset_schema.md` §3); truly re-acquired paired dose is a v1.0 distinction.
- **Single-source-annotation pushback**: "Most of your annotations are inherited from LIDC, not new." Address as a feature (harmonizing existing community annotations is the contribution; for the v1.0 roadmap we top up the AAPM/Mayo gaps rather than re-collect, saving ~$80K in annotation honoraria that would otherwise be wasted).
- **Journal-fit / "data vs. software" pushback** (addressed in the 2026-05-25 reframe): Data Records now *leads with the new deposited data records* (annotations, LIDC-derived simulated low-dose, harmonized metadata, splits, manifest), grouped by license/availability, so the descriptor is anchored on data rather than code; the loader/pipelines are positioned as the access mechanism. This is the single most important framing change for a *Scientific Data* desk-screen.
- **Blockchain-credibility / competing-interests pushback** (addressed in the 2026-05-25 reframe): PhysioNet DOI + Zenodo + the SHA-256 content hash are now the primary, journal-recognized deposit/citation channels; the IPFS replica and the PWM L3 registry entry are demoted to a single optional "mirror" sentence throughout (abstract, Data versioning, Code Availability); and the PWM Protocol Foundation affiliation is now declared in a real Competing Interests statement.
