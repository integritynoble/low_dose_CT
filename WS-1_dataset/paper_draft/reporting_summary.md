## 1. Statistics

For all statistical analyses, confirm the following are reported. *This descriptor performs no
hypothesis testing or inferential statistics; the only quantitative claim is a prospective
sample-size/power justification for the test split.*

- **Sample size & test statistics / effect sizes / p-values / CIs / multiple comparisons:** N/A —
  no inferential statistics are reported. Technical-Validation metrics (PSNR/SSIM/LPIPS, inter-rater
  κ, distributional distances) are descriptive summaries, not hypothesis tests.
- **Sample-size determination:** reported in Methods (§Sample-size justification): the aggregate
  test split (~250 patients) is sized to detect a paired AUC difference Δ ≥ 0.02 at α = 0.05,
  β = 0.20 (ρ ≈ 0.5, σ ≈ 0.10) ⇒ n ≳ 200; per-source sub-populations are flagged as underpowered.
- **Software for statistics:** descriptive metrics computed with NumPy / the released harness
  (`pwm_ldct_baselines`); no statistical-test software used.

## 2. Software and code

- **Data collection:** No new data collected. Source scans were acquired by the original release
  teams on clinical CT scanners (Siemens, GE) and distributed by NBIA / Mayo / TCIA. The
  reduced-dose data (AAPM/Mayo) was generated by Mayo's validated projection-domain noise-insertion
  software (by those teams, not us).
- **Data analysis:** All released software is open-source. `pwm_ldct_loader` v0.5.0 (loader +
  `validate`), `pwm_ldct_prep` v0.5.0 (de-identification, harmonization, low-dose simulation,
  HDF5/manifest writers), `pwm_ldct_baselines` v0.5.0 (RED-CNN train/eval). Dependencies: Python
  ≥3.9, PyTorch [CONFIRM version], NumPy ≥1.21, h5py ≥3.6, PyDICOM ≥2.3, Tesseract OCR
  [CONFIRM version]; low-dose simulation forward model `pwm_core.contrib.modalities.ct_radon`. All
  code, with versions, is at https://github.com/integritynoble/low_dose_CT and the PhysioNet/Zenodo
  deposit; the loader is on PyPI. Processing is deterministic (seed 42) and the outputs are
  verifiable against a SHA-256 manifest.

*Per Nature policy, the code that produces the released artifacts is publicly available and
documented (Code Availability in the manuscript).*

## 4. Field-specific reporting

Field selected: **Life sciences** (medical imaging). Behavioural/social and ecological summaries: N/A.

### Life sciences study design

- **Sample size:** All publicly available scans from the three sources were harmonized (no
  subsampling): LIDC-IDRI 1,018; AAPM 2016 10; Mayo LDCT-PD public 199 (one ACR phantom and 99
  GDC-restricted head subjects excluded); union ≈ 1,227. The test split is powered per §Statistics.
- **Data exclusions:** Pre-established and criterion-based: (i) Mayo head subjects (GDC
  credentialed-access — out of v0.5 scope); (ii) the ACR phantom (not a patient); (iii) any scan
  with a positive de-identification audit hit (none occurred). No data-driven exclusions.
- **Replication:** All harmonization is deterministic (fixed seed) and reproducible: the Docker
  pipelines regenerate bit-identical HDF5 verified against the SHA-256 manifest, and baseline
  results reproduce from the released container on equivalent hardware. No experimental replication
  applies (no new experiment).
- **Randomization:** Patients (not scans) are allocated to train/val/test (60/20/20) by a
  deterministic hash of the patient ID with a published seed, stratified by source and anatomy. No
  intervention/group allocation.
- **Blinding:** N/A — there is no intervention or group comparison. (Annotation note: top-up readers
  followed a calibrated protocol with discordance adjudication; they were not "blinded" in the
  experimental sense as no allocation exists.)
