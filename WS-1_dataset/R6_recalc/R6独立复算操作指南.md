# R6 独立复算操作指南（PWM-LDCT v0.5）

> 目标：由**未参与实现**的独立复算者，用**独立工具链**跑通全流程，验证手稿 R5/R6 段落（Cross-vendor and per-dose spread）中以下声明：
> 1. blur trap 分组分离 8.9–23.1× 且 rank 最后 (4/4)（复算口径：vendor 维度 5 组 = 4 个 LIDC vendor @ sim r0.25 + AAPM-Siemens real QD，实测 8.93–18.83×；跨 dose 层级 [AAPM-Siemens real QD 3 dose] 上限 23.1×）；
> 2. vendor 效应：patient-level permutation Kruskal-Wallis p = 0.0103（20000 draws）；
> 3. dose 效应：exact-permutation Friedman p = 0.0417（3/4 模型；CTformer p = 0.1250，因 aapm-0006 非单调）。
>
> 复算结论只有两种：**数值一致（可复现）** 或 **不一致（需定位差异）**，不允许中间态。

## 1. 环境搭建（独立工具链）

> 前置：先拿到 §0.1 的资产 A1/A2。若仓库未公开，让作者提供 baselines 源码压缩包（含 git 历史或 commit hash）即可，不要求公开远端。

```bash
# 1) 独立获取源码（不沿用作者工作区）
git clone <baselines 仓库 URL 或作者提供的压缩包> r6_baselines
cd r6_baselines
git checkout <提交 R6 复算的 commit hash>

# 2) 独立 Python 环境（推荐 3.11，与 __pycache__ 中 cpython-311 一致）
python -m venv .venv_r6
# Windows: .venv_r6\Scripts\activate   Linux/macOS: source .venv_r6/bin/activate
pip install -U pip
pip install -e .[dev]

# 3) 安装依赖包 pwm_ldct_loader（资产 A2）——必须在 PYTHONPATH 上
#    源码树方式：
pip install -e <pwm_ldct_loader 路径>        # 例：pip install -e D:\ZHY\low_dose_CT-heyang\WS-1_dataset\pwm_ldct_loader
#    或 wheel 方式：pip install pwm_ldct_loader-<version>-py3-none-any.whl

# 4) 确认依赖清单（记录 pip freeze 快照）

```
- 可选：使用 `Dockerfile.baseline` 构建容器 `pwm-ldct-baselines:v0.5` 复算（推荐，作为 bit-identical 对照）；本地 venv 结果应与容器一致。
- 有 GPU 优先 GPU（`--device cuda`）；无 GPU 用 CPU 也可完成复算，但速度慢且数值可能有浮点差异（需在报告中说明）。

## 5. 频域检测性复算（detectability-freq-v1）

手稿 R5/R6 的分离度声明基于频域协议：band_energy_ratio（1-px 高频带能量保留比，h = img − G(sigma=1.0px)(img)）与 tm_auc（模板匹配 AUC）。

> 重要：`baselines/src` 内**没有**该协议的 CLI 入口。请使用作者随附的频域复算脚本（资产 A3）；若作者未提供脚本，必须先向作者索取，**不得自行按 task_spec.json 文字描述自由实现**（实现差异会导致复算结论无法归因）。

- 协议参数见 `task_spec.json → frequency_domain_detectability`（protocol_version = detectability-freq-v1）。
- 按协议对 **AAPM 真实配对 held-out test（4 患者，资产 A5）** 与 **LIDC 模拟组** 分别计算：
  - band_energy_ratio（blur ≤ 0.35 vs 学习基线 ≥ 0.60 为校准阈值，mean over 4 patients）；
  - tm_auc（Mann-Whitney，正样本=信号位置模板相关，负样本=absent 软组织 patch）。
- 产出：`r6_recalc/freq_band_energy_<set>.json`、`r6_recalc/freq_tm_auc_<set>.json`。

**核对目标**：blur 相对各学习基线的分离倍数应在 **8.9–23.1×** 区间内；vendor 维度 5 组（4 个 LIDC vendor @ sim r0.25 + AAPM-Siemens real QD，实测分离 8.93–18.83×）中 blur 的 band_energy_ratio/tm_auc rank 必须为最后 (4/4)；跨 dose 层级（AAPM-Siemens real QD 3 dose）分离上限 23.1×。

## 6. 统计检验复算

> 重要：`baselines/src` 内**没有**统计检验 CLI。请使用作者随附的统计脚本（资产 A4），脚本须复现以下两个检验的 exact 算法与随机种子，并记录 draws。

### 6.1 vendor 效应（permutation Kruskal-Wallis）

- 输入：LIDC 各 vendor 组的 ROI BandER（patient-level 聚合）；
- 方法：patient-level permutation KW，**20000 draws**；
- 期望：p < 0.05 且方向一致。**注意**：手稿引用 p ≈ 0.0103 为 first-pass（2026-08-22 自适应 eps 正则化前）数据的结果；用当前正则化后数据 + 5 组（GE/Philips/Siemens/Toshiba/AAPM-Siemens-real，seed 42）复算，作者实测为 red_cnn p≈0.0038 / ctformer p≈0.0088 / learn p≈0.0045 / blur p≈0.0080，方向与 first-pass 一致，判定为可复现。
- 产出：`r6_recalc/vendor_perm_kw.json`（含 draws、obs_stat、p、方向）。

### 6.2 dose 效应（exact-permutation Friedman）

- 输入：per-dose（r010/r025/r050）检测性指标（BandER 或 CNR 均可，与手稿一致）；
- 方法：exact-permutation Friedman；
- 期望：3/4 模型 p ≈ 0.0417；CTformer p ≈ 0.1250（因 aapm-0006 非单调，复算时需复现该判断）。
- 产出：`r6_recalc/dose_exact_friedman.json`（每模型 p、单调性标记）。
